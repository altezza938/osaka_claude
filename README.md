# 大阪 2026 · 家庭旅程手冊

一個單頁、離線可用的家庭旅程手冊，為 2026 年 8 月 5–9 日大阪／京都之行而做。

**行程**：2026年8月5日（三）— 8月9日（日）· 5日4夜 · 7位成人 + 1位嬰兒

## 內容

| 分頁 | 內容 |
| --- | --- |
| 今日 | 即時倒數、當日重點、行程概覽、特別提醒 |
| 航班 | 去程 HX616 / 回程 UO689、登機安排、行李限額 |
| 住宿 | 桃谷 Airbnb 地址（可複製給司機）、前往方法、屋規 |
| 行程 | 每日時間表，可切換「原定行程」與「建議行程」；每個景點有 Google 地圖導航掣 |
| 票券 | USJ 門票、租車詳情（Toyota Vellfire 8座） |
| 旅遊書 | 掃描頁面相簿（燈箱瀏覽，可左右掃） |
| 資訊 | 緊急電話、實用日語、駕駛及泊車貼士 |

## 使用

`index.html` 是一個完全獨立的檔案——冇任何外部 CSS、JS 或圖片依賴。直接用瀏覽器開就得，亦可以放上任何靜態網頁寄存服務（GitHub Pages、Netlify 等）。

手機加到主畫面就最方便：所有內容都喺檔案入面，落機冇網絡都睇得到（地圖同外部連結除外）。

## 設計

- 為手機而設，底部固定七個分頁
- 自動跟隨系統淺色／深色模式
- 支援 `env(safe-area-inset-*)`，iPhone 瀏海及底部橫條唔會擋住內容
- 尊重 `prefers-reduced-motion`

## 加旅遊書內頁

打開 `index.html`，搵 `var BOOK = [];`，按格式加入：

```js
var BOOK = [
  { src: "data:image/jpeg;base64,...", cap: "大阪城周邊地圖" },
  { src: "images/p02.jpg", cap: "京都一日遊" }
];
```

用 `data:` base64 就可以保持單檔案、完全離線。
